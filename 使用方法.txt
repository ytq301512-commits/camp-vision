阵营识别 Camp Vision 使用方法
================================

一、启动
--------
双击 CampVision.exe。桌面版无需卡密、机器码或联网激活，解压后保持目录结构不变即可使用；首次启动可能需要几秒加载 OCR 模型。

二、准备人物库
--------------
1. 打开左侧“人物库”。
2. 每个人物填写：人物名、阵营、别名。
3. 点击“保存人物库”。
4. 别名可以填写 OCR 容易识别错的写法，多个别名用英文逗号分隔。

三、框选识别
------------
1. 回到“实时识别”。
2. 点击“框选范围”。
3. 在屏幕上拖动框住人物卡片底部的名称区域。
4. 点击“开始识别（当前范围）”。
5. 匹配成功后，卡片上方会显示对应阵营；完整人物名会显示在结果表格中。

注意：框选范围必须包含人物名称文字。牌面互相遮挡时，软件会尝试用唯一的首字匹配；首字对应多个人物时不会猜测。

四、识别设置
------------
- 识别间隔：最低 100ms，可按 100ms 调整。OCR 本身通常需要约 200ms，建议使用 100-300ms。
- 硬件加速：OCR 使用可用的 CUDA 或 DirectML；卡图匹配使用 OpenCL GPU。状态栏会显示实际后端，不可用时自动使用 CPU。
- 保存配置：开启后保存框选范围、识别间隔和 GPU 设置；关闭后下次启动恢复默认。
- 分辨率：点击“分辨率”按钮，选择或填写显示器实际像素分辨率（例如 2560×1600）。软件会用该分辨率把框选坐标换算为截图坐标；选择“自动”则使用 Windows DPI。

五、重新框选
------------
点击“框选范围”重新拖动即可。程序会按 Windows 显示缩放自动换算截图坐标，适配 2560×1600 等高 DPI 屏幕。

六、常见问题
------------
- 没有识别结果：请重新框住底部人物名称，而不是卡片图片区域。
- 标签位置不准：重新框选一次，确保名称文字完整且同一排卡片在框内。
- 速度较慢：确认状态栏显示“卡图 OpenCL GPU”，并缩小框选区域；不要把整个游戏窗口都框进去。
- 启动失败：请确认解压后运行，不要只复制 CampVision.exe 一个文件。

人物库文件位于 data\roster.json，可备份、复制到另一份发布目录，或在软件中导入/导出 JSON、CSV。
卡面识别说明：软件会同时使用卡图模板和 OCR。卡图可在文字被遮挡时补充识别，OCR 会对清晰文字进行校验。发布包中的 `_internal/assets/card_templates` 是内置卡图模板，请不要删除。
